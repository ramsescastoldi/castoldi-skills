# castoldi-skills
skills de geração de post e carrossel.

## Superpowers

As skills abaixo vêm do projeto [obra/superpowers](https://github.com/obra/superpowers) (MIT, ver `LICENSE-superpowers`) — um framework de metodologia de desenvolvimento de software para agentes de código:

- `brainstorming` — refina ideias em designs antes de implementar
- `writing-plans` — escreve planos de implementação detalhados
- `executing-plans` — executa planos em fases com checkpoints
- `test-driven-development` — TDD (red/green/refactor)
- `systematic-debugging` — debugging sistemático em 4 fases
- `requesting-code-review` / `receiving-code-review` — fluxo de code review
- `verification-before-completion` — verificação antes de declarar pronto
- `finishing-a-development-branch` — finalização de branch (merge/PR/cleanup)
- `using-git-worktrees` — trabalho isolado em git worktrees
- `dispatching-parallel-agents` / `subagent-driven-development` — orquestração de subagentes
- `writing-skills` — criação e manutenção de skills
- `using-superpowers` — introdução ao sistema de skills

## Ponytail

As skills abaixo vêm do projeto [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (MIT, ver `LICENSE-ponytail`) — um sistema que faz o agente escrever o mínimo de código necessário ("o melhor código é o que você nunca escreveu"):

- `ponytail` — modo de escrita de código mínimo (YAGNI, reuso, stdlib antes de código novo)
- `ponytail-review` — revisa um diff procurando over-engineering
- `ponytail-audit` — audita o repositório inteiro procurando bloat
- `ponytail-debt` — coleta os comentários `ponytail:` num ledger de dívidas técnicas
- `ponytail-gain` — mostra o impacto medido do ponytail (scoreboard)
- `ponytail-help` — ajuda sobre o sistema
