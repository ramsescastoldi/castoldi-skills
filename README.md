# castoldi-skills
skills de geração de post e carrossel.

## Superpowers (skills de engenharia de software)

As skills abaixo vêm do projeto [obra/superpowers](https://github.com/obra/superpowers)
(MIT License, Jesse Vincent — ver `LICENSE-superpowers.txt`):

- `brainstorming` — refinar ideias em designs antes de implementar
- `writing-plans` — escrever planos de implementação detalhados
- `executing-plans` — executar planos em lote com checkpoints de revisão
- `test-driven-development` — TDD (RED-GREEN-REFACTOR)
- `systematic-debugging` — debugging sistemático (causa raiz em 4 fases)
- `verification-before-completion` — verificar antes de declarar concluído
- `requesting-code-review` / `receiving-code-review` — pedir e receber code review
- `subagent-driven-development` — desenvolvimento com subagentes
- `dispatching-parallel-agents` — despachar agentes em paralelo
- `using-git-worktrees` — trabalhar com git worktrees isolados
- `finishing-a-development-branch` — finalizar branch de desenvolvimento
- `writing-skills` — criar e testar novas skills
- `using-superpowers` — introdução ao sistema de skills
