## 3. SISTEMA VISUAL "DIVISÃO"

**Conceito:** a tela parte em duas por uma linha de ouro. Em cima a **foto** (a prova). Embaixo a **sentença** sobre papel (o veredito).

### Paleta (fixa)
| Cor | HEX | Uso |
|-----|-----|-----|
| Papel | `#F4EFE4` | fundo do painel de texto |
| Tinta | `#181612` | texto principal (preto quente) |
| Tinta suave | `#4A453C` | sublinha/apoio |
| **OURO** | `#B0852E` | **1 palavra** de destaque + réguas + monograma |
| Mudo | `#847C6C` | rótulos, índice, @ |
| Régua | `#D0C8B8` | bordas finas |
| (Vermelho) | `#B0322B` | exceção rara p/ denúncia — substitui o ouro, nunca soma |

**Regra de ouro: apenas UMA palavra colorida por peça.**

### Tipografia
- **Manchete/tese:** Lora Bold (serifa editorial) — 1 palavra em ouro.
- **Rótulo/kicker/índice/assinatura:** IBM Plex Mono (caixa-alta, tracking) com quadradinho de ouro.
- **Monograma RC:** Gloock (selo do rodapé + marca d'água da foto).
- **Sublinha:** Crimson Pro Italic (tinta suave).

### Estrutura
Rótulo branco sobre a foto → FOTO (54% no post/capa, 60% no reels) → **régua de ouro (a divisão)** → kicker mono → manchete serifa → sublinha itálica → régua → rodapé fixo (RC + RAMSES CASTOLDI + @eusouramses + índice). Carrossel leva número de página ("02 / 06").

### Formatos
Post 1080×1350 · Carrossel 1080×1350 (capa/ato/cta) · Reels 1080×1920. Sempre render **2×**.

## 4. FÓRMULA DE TEXTO (herda o que viraliza)
`TESE CONTRACORRENTE + NEGAÇÕES EM CADEIA + DEFINIÇÃO + [[palavra-ouro]] + sublinha seca`
- Kicker = a "seção do jornal" (ex.: O QUE NINGUÉM TE CONTA, ATO 02, DENÚNCIA).
- Legenda ~1100 chars, 7 blocos, autoridade com ANO (Mises 1949 / Hayek 1944 / Bastiat 1850 / Friedman 1962 / Schumpeter 1942), CTA mentoria 1:1.
- Funil de 4 stories: 1h teaser / 4h enquete / 8h frase-bomba / 20h CTA.
- **REGRA INVIOLÁVEL:** atacar culturas, narrativas e sistemas — **nunca pessoas ou grupos**.
