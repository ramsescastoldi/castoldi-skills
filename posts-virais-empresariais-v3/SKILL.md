## ESTRUTURA DA LEGENDA (7 BLOCOS — ~1100 chars)

### Bloco 1 — Diagnóstico universal (1 frase)
Abre com a verdade que ninguém fala. Ex: "Existe uma narrativa que o empresário precisa entender..."

### Bloco 2 — Veredito seco (1-2 frases)
A denúncia em 2-3 palavras. Ex: "O Estado não regula. Pune."

### Bloco 3 — Argumento com fatos (4-6 frases)
Lista concreta. Dados, etapas, exemplos específicos. NUNCA abstrato.

### Bloco 4 — Autoridade filosófica
SEMPRE COM ANO. Escolha um:
- **Mises 1949** (mercado, ação humana, planejamento central)
- **Hayek 1944** (caminho da servidão, conhecimento disperso)
- **Bastiat 1850** (o que se vê e o que não se vê, Estado)
- **Friedman 1962** (capitalismo e liberdade)
- **Schumpeter 1942** (destruição criativa, empreendedor)

### Bloco 5 — Frase-bomba memorável
O que vira print/story. Sempre antitética: "X é vício. Y é remédio."
Exemplos validados:
- "Empresário forte não trabalha mais. Pensa antes."
- "País sério facilita quem produz. País falido pune."
- "Reclamação é placebo. Estudo é remédio."

### Bloco 6 — Pergunta binária polarizadora
Força o leitor a se posicionar mentalmente.
- "X — ou Y?"
- "Ainda acha que [premissa]?"

### Bloco 7 — CTA mentoria (PADRÃO FIXO)
```
—

Se você leu até aqui e sentiu o soco, é porque [conexão com tema do post].

Eu trabalho lado a lado com empresários que decidiram [transformação relacionada].

Não é pra todo mundo. É pra empresário que aceita ser desafiado de perto.

Vagas limitadas. Processo seletivo no link da bio.

🔗 @eusouramses
```

## CÓDIGO PYTHON DE RENDERIZAÇÃO (executar sempre)

```python
from playwright.sync_api import sync_playwright
import os
from datetime import datetime

# 1. Ler template master
template_path = '/home/claude/posts-virais-template-v3/template_master.html'
with open(template_path, 'r') as f:
    html = f.read()

# 2. Substituir variáveis
QUOTE_CLASS = "quote-xl"  # escolher conforme número de linhas
QUOTE_TEXT = """SEU TEXTO COM <br> E <span class="red">PALAVRA</span> AQUI"""
FOOTER_MARK = "ESTRATÉGIA"

html = html.replace('QUOTE_CLASS', QUOTE_CLASS)
html = html.replace('QUOTE_TEXT', QUOTE_TEXT)
html = html.replace('FOOTER_MARK', FOOTER_MARK)

# 3. Salvar HTML temporário
tmp_path = '/home/claude/post_temp.html'
with open(tmp_path, 'w') as f:
    f.write(html)

# 4. Renderizar
data_str = datetime.now().strftime('%Y%m%d_%H%M')
output_path = f'/mnt/user-data/outputs/post_{data_str}.png'

with sync_playwright() as p:
    browser = p.chromium.launch()
    context = browser.new_context(
        viewport={'width': 1080, 'height': 1350},
        device_scale_factor=2
    )
    page = context.new_page()
    page.goto(f'file://{tmp_path}')
    page.wait_for_load_state('networkidle')
    card = page.locator('#capture-card')
    card.screenshot(path=output_path)
    browser.close()

print(f"PNG gerado: {output_path}")
```
